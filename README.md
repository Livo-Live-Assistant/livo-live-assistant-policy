# livo-live-assistant-policy

Hospedagem das páginas legais públicas do **Livo**.

O repositório existe apenas para servir os documentos em URL pública, como exigido no
cadastro do aplicativo na plataforma TikTok.

## Publicação

GitHub Pages, servindo a raiz do branch `main`
(*Settings → Pages → Source: Deploy from a branch → main / (root)*).

| Documento | URL |
|---|---|
| Termos de Serviço | `https://livo-live-assistant.github.io/livo-live-assistant-policy/terms/` |
| Política de Privacidade | `https://livo-live-assistant.github.io/livo-live-assistant-policy/privacy/` |

Os arquivos `terms.html` e `privacy.html` na raiz são redirecionamentos, mantidos para não
quebrar URLs já cadastradas.

Todas as páginas trazem `<meta name="robots" content="noindex, nofollow">`. Elas devem
permanecer acessíveis por URL direta e fora dos buscadores.
